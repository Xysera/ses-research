# Sandbagging Evidence Standard research

Public research repository for *Toward an Evidence Standard for Sandbagging Claims*.

**Author:** Torin Ethreidge, Lead Researcher and Senior Researcher, Xysera Research  
**Status:** preprint v1.0-rc1; SES decision rules v0.5; not peer reviewed  
**Repository:** https://github.com/Xysera/ses-research

## Release artifacts

- `releases/xysera-ses-v1.0-rc1-paper.pdf` — preprint.
- `releases/xysera-ses-v1.0-rc1-source.tar.gz` — reproducible source package.
- `releases/xysera-ses-v1.0-rc1-data.tar.gz` — five confirmatory logs and derived outputs.
- `releases/RELEASE_SHA256SUMS_v1.0-rc1.txt` — release checksums.
- `prereg/PREREGISTRATION.md` and `prereg/MANIFEST.txt` — frozen Study 1 protocol and digest.

See `sandbagging-standard/REPRODUCE.md` for reproduction commands and `sandbagging-standard/PUBLICATION_CHECKLIST.md` for current limitations and release status.

## Main finding

Matched neutral context reproduced almost all accuracy degradation attributed to penalty notes. Three Study 1 models are classified L1-ctx and two are statistically indeterminate; none supports consequence-sensitive underperformance. The SES is an auditable proposal, not a validated detector, and no level establishes intent.

## Large files

Model weights and local runtime environments are intentionally excluded. Model identifiers and SHA-256 hashes are recorded so independently obtained weights can be checked. The release data archive contains the five complete confirmatory logs used in the paper.
